# 憶起照顧｜長照需求與費用指南

透過簡單問答，協助家屬了解可洽詢的長照服務、所在地申請入口、分階段準備資料，以及照顧及專業服務的費用概算。

[開啟目前網站](https://care-guide-tw-20261112.lynnctc.chatgpt.site/)

本專案為純 HTML、CSS 與 JavaScript 靜態網站，無需安裝前端套件或執行建置。服務建議採明確的條件規則，不使用外部 AI 模型。

## 功能

- 六步需求探索：居住縣市、年齡、身分與健康、生活困難、希望支持、照顧安排及正式評估進度。
- 依需求排序服務建議，說明推薦原因；可直接修改單題回答。
- 分別處理社區支持、尚待評估、已有正式等級、外籍家庭看護及住宿機構情境。
- 提供全臺 22 縣市的官方申請入口與照管窗口電話。
- 依「先諮詢」「申請／評估」「核定後」整理可勾選的準備清單。
- 照顧及專業服務單月費用概算：服務總額、額度內部分負擔、超額自費與政府分擔。
- 區分正式核定資料與假設情境，提供大字模式、分頁暫存、文字摘要下載、列印／另存 PDF。

## 使用方式

1. 以需要被照顧者的狀況完成問答；不清楚的項目可選不確定。
2. 查看服務建議與推薦原因，找到所在地官方申請入口。
3. 勾選已準備的資料，依個別狀況和照管中心確認正式要求。
4. 如需估算費用，選擇正式等級或假設情境，再填身分別、聘僱情況及服務次數／報價。
5. 下載文字摘要或列印清單，方便與家人及專員討論。

問答不會核定長照資格、推算失能等級或作出醫療診斷；服務與給付仍由主管機關及照管中心確認。

## 本機執行

需先安裝支援 ES Modules 與內建測試執行器的 Node.js。以下命令均在 `care-guide` 專案根目錄執行：

```sh
node scripts/preview.mjs
```

開啟 [本機預覽](http://127.0.0.1:4173/)，結束時在終端按 `Ctrl+C`。

請透過 HTTP 伺服器預覽；直接雙擊 `index.html` 使用 `file://` 開啟，可能因瀏覽器對 ES Modules 的限制而無法執行。

## 檢查與測試

```sh
node --check dist/app-v2.js
node --check dist/data.mjs
node --test tests/logic.test.mjs
```

目前有 20 項自動測試，涵蓋身分與年齡分流、社區及機構情境、外籍看護、推薦排序、額度與部分負擔等。驗證紀錄見 [VALIDATION.md](VALIDATION.md)。

真人家屬、高齡使用者及螢幕閱讀器測試尚未執行；測試任務與通過目標見 [USER_TEST_PLAN.md](USER_TEST_PLAN.md)。

## 上傳 GitHub 與 GitHub Pages

### 保留完整專案原始碼

可將本 README、`dist/`、`scripts/`、`tests/` 及兩份驗證文件上傳至新的 GitHub Repository。

目前本機專案已連接 Sites 的 Git 儲存庫。若要另建 GitHub 版本，建議複製上述檔案至獨立資料夾，不要更動現有遠端。不要複製 `.git/`、`.openai/`、憑證、部署壓縮檔或真實使用者資料。

### 最簡單的 GitHub Pages 部署方式

1. 建立專門放網站的新 Repository，例如 `care-guide-tw`。
2. 將 `dist/` **裡面的五個檔案**上傳到 Repository 根目錄，並可一併上傳本 README。
3. 開啟 Repository 的 **Settings → Pages**。
4. 選擇 **Deploy from a branch**，指定 `main` 分支與 `/(root)`，儲存後等待部署。
5. 以 GitHub Pages 設定頁顯示的網址確認部署結果。

專案型網站網址通常為 `https://你的帳號.github.io/care-guide-tw/`。本網站使用相對路徑，可放在這類子路徑下。

若完整保留目前的 `dist/` 結構，不能直接把它選為分支發布資料夾；GitHub Pages 的分支發布來源支援根目錄或 `/docs`。此時可另外以 GitHub Actions 發布 `dist/`，或將網站內容整理到 `/docs`。

本專案尚未附上 GitHub Actions 工作流程；只有新增 README 不會自動上傳 GitHub 或啟用 Pages。步驟依據：[GitHub Pages 官方發布來源設定](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site)。

## 費用試算範圍

- 僅估算單月「照顧及專業服務」（B／C 碼），不合併交通接送、喘息及輔具等獨立額度。
- 提供部分常見居家服務的價格範例；其他適用服務須依單位報價輸入。
- 依輸入等級、長照身分別、外籍看護聘僱情況與可用額度計算。
- 未取得核定資料時，只能作假設比較；不代表已取得資格、等級或給付。
- 以月總額概算部分負擔，實際逐筆計價與捨去方式可能造成差異。
- 超額部分為自費概算；服務單位的實際自費價格仍需另行確認。
- 不處理跨月保留、全部服務碼別、特殊例外、未滿月自動換算及完整時段併用規則。
- 機構照顧不套用本工具的一般居家及社區月額度試算。

額度是可使用的服務額度，不是直接發給使用者的現金補助。精確費用與服務安排，請由個案管理員及服務單位確認。

## 文件與地方資訊限制

本工具提供的是申請前準備清單，不是各縣市完整正式送件文件。正式申請表、代理授權、診斷資料及輔具核銷等要求，請透過所在地官方入口確認。

縣市入口取自衛福部目錄，部分地方站點在查核時讀取逾時；若連結失效，可改用官方目錄或窗口電話。本工具不代填或代送申請。

## 隱私與資料保存

- 不要求姓名、身分證字號或詳細地址；問答回答不由應用程式傳送到伺服器。
- 預設僅留在頁面記憶體；使用者主動啟用暫存後，使用瀏覽器 `sessionStorage` 保留此分頁進度。
- 可停止暫存並清除儲存內容，或以「重新開始」清除回答與暫存。
- 下載摘要及列印檔案會包含使用者選擇的照顧需求，請自行妥善保存。
- 外部政府網站與網站託管服務各有自己的隱私政策及技術紀錄。
